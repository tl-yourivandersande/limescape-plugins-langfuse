# Coding-agent instructions

This repository contains dynamic node types for Limescape AI Platform. These
instructions apply to agents working here, including Claude Code via `CLAUDE.md`.

## Read before implementing

1. Read [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
2. Follow [the node-type workflow](docs/agent-node-types.md).
3. For any authenticated integration, read
   [the credential contract](docs/credentials-and-node-types.md) before designing
   fields or writing HTTP calls.
4. Inspect the closest existing node and its tests.

## Boundaries

- Create `src/node-types/<code>/node-type.yaml`, `node.py`, `i18n/nl.json`,
  `i18n/en.json`, `README.md` and behavior tests. Folder name equals manifest code.
- The plugin entry point is an async generator: `execute(ctx, inp)`.
  Import only the standard library, `limescape_plugin_sdk`, declared third-party
  dependencies and relative helpers inside the same node folder.
- Never import `truelime_ai`, Django, another node type or platform tracing decorators.
- Keep nodes stateless; never cache credentials or request data globally.
- Never log or return secrets or raw responses of external services.
- Use bounded HTTP calls and safe errors. Use synthetic test data only.

## Generated files

`src/node-types/juridische_adviseur_fase_a/_evaluators.py`, `_contract.py`, `_version.py` and
`uitvoercontract.json` are generated by `scripts/sync_fase_a_checks.py` from the evals repository.
Never edit them here: change the source and run the script. A check that needs to change is a change
to the evals repository, reviewed there.

## Langfuse wire format

`src/node-types/langfuse_evaluation/_otel.py` reproduces what the Langfuse Python SDK sends for an
experiment item. Do not adjust attributes by reasoning: capture a current SDK against a recording
server and update the module and its test together.

## Verification

Use Python 3.12 and follow docs/agent-node-types.md. Report which checks actually ran and any
remaining platform, release or activation prerequisites.
